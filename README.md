# REAL GAME PMS (Property Management System)

A premium, modern, gaming-inspired professional Property Management System (PMS) and Enterprise Resource Planning (ERP) application.

## Rebranding Overview
This project has been visually rebranded from **Mystery Rooms** to **REAL GAME**, adopting a high-end, cyber-inspired dark aesthetics palette:

- **Primary Accent:** Purple (`#7C3AED`)
- **Secondary Accent:** Blue (`#2563EB`)
- **Branding Highlights:** Rose (`#F43F5E`)
- **Surfaces & Backgrounds:** Cool gaming slate & ink dark colors

All operations, workflows, APIs, databases, and permissions remain unchanged.

## Getting Started

### 1. Prerequisites
- **Node.js** (v18+ recommended)
- **MongoDB** instance

### 2. Running the Backend Server
```bash
cd server
npm install
npm start
```
*Port configuration and database URI can be found in `server/.env`.*

### 3. Running the Frontend client
```bash
cd client
npm install
npm run dev
```
*The dev server will run locally at [http://localhost:5173](http://localhost:5173).*
